## Order
1. File list and README.
2. Build files and scripts: they name the real commands.
3. CI config: it shows what is actually run on every change.
4. A few representative sources and tests for conventions.

## Accuracy
Write a command in HEXAGON.md only if a script, CI file or README shows it. Mark anything inferred as "unverified".
